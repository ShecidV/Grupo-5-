# 🅰️ Frontend (Angular 21)

## 🛠️ Comando de Instalación Directa

```powershell
npm install
```

> **Librerías instaladas:** `@angular/core`, `@angular/router`, `@angular/forms`, `@angular/common`, `zone.js`, `rxjs`.

---

## 🚀 Comandos para Levantar el Frontend

```powershell
# Iniciar servidor de desarrollo
ng serve
```

* **URL Frontend:** http://localhost:4200
